마감벨은 지역 매장의 마감 할인 상품을 찾는 앱입니다. 2025년 App Store와 Play Store에 출시했고, 지금은 서비스를 종료했습니다. 아래 1~3번은 마감벨에서, 4번은 포인토에서 겪은 문제입니다.

네 문제 모두 비즈니스 로직만 고쳐서는 풀리지 않았습니다. 내비게이션 구조, 네이티브 라이브러리 의존성, 그래픽 리소스의 생명주기를 따라가 원인을 찾았고, 실기기에서 확인했습니다.

## 1. 화면 전환 3번 중 1번꼴로 탭바가 남거나 빈 영역이 보임

- **진단**: 스택 화면으로 넘어갈 때 간헐적으로 생겨서 재현 조건을 하나로 고정하기 어려웠습니다. 디버깅 로그, React Navigation 공식 문서, 비슷한 이슈 사례를 하나씩 대조하며 원인을 지워 나갔습니다.
- **원인**: 탭 네비게이터 안에 전체 화면 흐름까지 넣고, 화면이 바뀔 때마다 탭바 노출 여부를 손으로 제어하고 있었습니다. 전환 타이밍에 따라 렌더링 순서가 어긋나면서 UI가 깨졌습니다.
- **해결**: 루트 네비게이터 아래에 탭(`MainTab`)과 전체 화면 스택(`FullScreenStack`)을 나눠 배치했습니다. 전체 화면이 탭 영역 밖에서 열리니, 탭바를 손으로 숨기는 로직 자체가 필요 없어졌습니다.
- **결과**: 화면 전환 때 탭바와 GNB가 남거나 빈 공간이 생기는 현상이 다시 나오지 않았습니다.

## 2. iOS에서 NAVER Map 타일이 그려지지 않음

- **진단**: 지도 화면 코드, 라이브러리 버전, 앱의 New Architecture 설정을 하나씩 교차 확인하며 범위를 좁혔습니다.
- **원인**: 지도 라이브러리의 New Architecture(Fabric) 지원 여부와 앱의 Fabric 활성화 설정이 맞지 않았습니다.
- **해결**: 지도 라이브러리를 Fabric을 공식 지원하는 버전으로 올렸습니다.
- **결과**: iOS 실기기에서 지도 타일이 정상으로 나옵니다.

## 3. Android에서 현재 위치를 조회하면 앱이 바로 종료됨

- **진단**: Android Studio Logcat에서 크래시 스택 트레이스를 따라가 `play-services-location` 버전 불일치 오류를 찾았습니다.
- **원인**: 위치 라이브러리와 다른 의존성 패키지가 서로 다른 버전의 `play-services-location`을 부르면서 네이티브 빌드와 런타임이 충돌했습니다.
- **해결**: Android Gradle 설정(`resolutionStrategy` 등)에서 `play-services-location`을 한 버전으로 강제 통일했습니다.
- **결과**: 위치 조회 때 나던 네이티브 크래시가 사라졌습니다.

## 4. iOS에서 화면 전환을 반복하면 메모리가 쌓여 강제 종료됨 (포인토)

- **진단**: Xcode 콘솔에서 화면이 바뀔 때마다 `CGBitmapContextCreate` 로그가 쌓이는 것을 보고, 그래픽 메모리를 잡고 있는 컴포넌트를 거꾸로 찾아갔습니다. Xcode Instruments로 실제 메모리가 늘어나는 것도 확인했습니다.
- **원인**: 화면 배경에 쓴 SVG 컴포넌트가 전환 때마다 비트맵 리소스를 풀지 않고 쌓고 있었습니다.
- **해결**: 문제의 SVG 배경 컴포넌트를 걷어 내고, 메모리를 덜 쓰는 방식으로 리소스를 다시 구성했습니다.
- **결과**: 화면 전환을 반복해도 메모리가 쌓이거나 앱이 종료되지 않습니다.
